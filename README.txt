STOCK RESTO V2
==============
Web-app/PWA prête pour un hébergement statique gratuit.

Fichiers :
- index.html : application
- manifest.json : installation sur téléphone
- sw.js : fonctionnement hors connexion après première visite
- icon.svg : icône

Pour la mettre gratuitement en ligne :
1. Créer un compte GitHub.
2. Créer un dépôt public nommé stock-resto.
3. Envoyer ces 4 fichiers à la racine.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. GitHub fournit une adresse https://...github.io/stock-resto/
6. Ouvrir cette adresse dans Safari puis Partager > Sur l'écran d'accueil.
